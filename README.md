# Свои запуски — лендинг эфира «Маркетинг 2026»

Одностраничный лендинг-приглашение на бесплатный эфир «МАРКЕТИНГ 2026: ТРЕНДЫ, КОТОРЫЕ ПРИНЕСУТ ДЕНЬГИ».
Аудитория — сёстры-эксперты, ведущие блог без лица и голоса. Цель страницы — собрать ники в Telegram.

Ключевая метафора — телевикторина «Своя игра», переименованная в **«СВОИ ЗАПУСКИ»**: игровое табло
4 колонки × 5 клеток с ценами 100–500. Клетки не раскрываются — интрига до эфира.

## Структура

```
index.html          — весь сайт: разметка, стили, логика (без сборки и зависимостей)
uploads/avatar.png  — аватар Юлии
.nojekyll           — отключает обработку Jekyll на GitHub Pages
```

Страница статическая и самодостаточная: единственный внешний ресурс — шрифт Golos Text с Google Fonts.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://127.0.0.1:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
Файл `.nojekyll` уже в репозитории, поэтому дополнительная сборка не нужна.

## Настройка

Параметры эфира собраны в объекте `CONFIG` в начале `<script>` в `index.html`:

| Параметр     | Значение по умолчанию       | Назначение                                  |
|--------------|-----------------------------|---------------------------------------------|
| `airDate`    | `29 июля · 14:00 МСК`       | подпись даты на странице                    |
| `airDateISO` | `2026-07-29T14:00:00+03:00` | целевое время таймера обратного отсчёта     |
| `catInBag`   | `true`                      | пасхалка «Кот в мешке» на случайной клетке  |

Контент (боли, темы, кейсы, заголовки колонок) — массивы `PAINS`, `TOPICS`, `CASES`, `COLUMN_TITLES` там же.

## Секции

1. **Hero** — заголовок, подзаголовок, таймер обратного отсчёта, CTA, дата.
2. **Игровое табло «Свои запуски»** — 4 колонки × 5 клеток, каскадное появление, hover-подсветка.
3. **«Этот эфир для вас, если»** — 8 пунктов болей.
4. **«Что вы узнаете на эфире»** — 6 карточек в стиле клеток табло.
5. **«Обо мне»** — аватар, цифра 40 млн ₽, 9 строк кейсов.
6. **Форма регистрации** (`#reg`) — одно поле: ник в телеграме.

## Поведение

- **Таймер** тикает раз в секунду до `airDateISO`, с ведущим нулём и русской плюрализацией подписей
  (день/дня/дней и т.д.). После наступления времени вместо таймера — пилюля «ЭФИР УЖЕ ИДЁТ».
- **Табло**: клетки появляются каскадом (`cellIn`, задержка `0.05 × (колонка + строка × 1.4)` с),
  на hover приподнимаются и подсвечиваются золотом. Содержимое не раскрывается.
- **Пасхалка «Кот в мешке»**: одна случайная клетка, выбирается один раз при загрузке. На устройствах
  с мышью показывается по наведению, на тач-устройствах — по тапу.
- **Форма**: пробелы вырезаются, «@» подставляется автоматически, лишние «@» удаляются. Валидация —
  минимум 3 символа, при ошибке показывается видимое сообщение. Успех переключает карточку в «ВЫ В ИГРЕ».
- **CTA в hero** — плавный скролл к форме (offset −24px).
- **Адаптивность**: mobile-first, всё на `clamp()` и `auto-fit`-сетках, медиа-запросов нет.
  Табло 4 → 2 колонки. Минимальный тач-таргет 44px.

## Что осталось подключить

1. **Приём заявки** — формы отправляются только в интерфейс, бэкенда нет. Точка подключения помечена
   комментарием `open item #1` в обработчике `submit` в `index.html` (Telegram-бот / CRM / вебхук).
2. **Аналитика** — события клика по CTA и отправки формы.
3. **Подтвердить дату и время эфира** в `CONFIG.airDateISO` перед запуском рекламы.

## Ограничения дизайна

Фотографий людей, лиц и рук на странице быть не должно — принципиальное ограничение аудитории.
Только типографика, табло, геометрия и мягкое свечение.
